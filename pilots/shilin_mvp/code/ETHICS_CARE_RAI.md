# Ethics and CARE note

The pipeline observes public Solana transaction data and the exact metadata URIs declared by those transactions. It does not collect social posts, images, account pages, chat content, or external webpage text, and it does not infer identity, account control, official status, or fraud.

The running program does not stop for a manual review. Raw third-party responses stay in the run directory. AI assistance is not written into the observation tables.
