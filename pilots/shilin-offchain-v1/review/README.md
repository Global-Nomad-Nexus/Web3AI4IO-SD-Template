# Human review exports

These CSV files are generated by `export_review_tables.py` from the SHA-256-verified fixed release. They do not add new observations or modify Claire's data.

| File | Rows | Unit and use |
|---|---:|---|
| `count_waterfall.csv` | 7 | Sequential selection counts from 91,484 platform records to 116 eligible creation events. |
| `coverage_ledger.csv` | 116 | One row per eligible event, including BSC access restrictions and unattempted cases. |
| `unmatched_cases.csv` | 87 | All events without an observed covered URL field: 32 successful JSON responses with no such field, 3 HTTP-403 BSC probes and 52 BSC events not attempted. This is a review queue, not a list of projects without websites. |
| `fourmeme_exact_queue.csv` | 55 | Exact BSC contract address and `requestId` from Claire's decoded `TokenCreate` event, for authorized source follow-up. |

The 61 Pump.fun creation events have 61 nonempty URI fields but only 57 distinct URI values. The original `ipfs.io` gateway returned 37 HTTP 429 responses; a second public gateway returned parseable JSON for all 57 distinct URIs. Thus this fixed run has **zero final URI-unavailable and zero parse-error cases**. The exact field-only linkage rule yielded **zero ambiguous or rejected candidates**; that says nothing about website ownership or precision. A `website` field pointing to an X post is retained as a field declaration with a `social_post` target class; see `../REVIEW_EXAMPLES.md`. A future expanded cohort must sample true conflicts and inaccessible sources separately rather than inventing examples here.

The raw third-party JSON bodies remain outside the public release while redistribution rights are unresolved. Request receipts, hashes, pointers and extracted factual fields are in `../release/`. 

`claire_reproduction_shilin.json` is Shilin's independent local execution receipt for Claire's unchanged notebook; it is a review artifact rather than a modification to Claire's release.
