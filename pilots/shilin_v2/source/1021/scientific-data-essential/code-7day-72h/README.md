## 四个观察点

| 观察点 | 计划时间 | 工程迟到上限 |
|---|---|---|
| T0 | 第一次解码到该创建事件 | 首次解码后 5 分钟 |
| T24 | 该事件的区块时间加 24 小时 | 计划后 1 小时 |
| T48 | 区块时间加 48 小时 | 计划后 2 小时 |
| T72 | 区块时间加 72 小时 | 计划后 3 小时 |

T24/T48/T72 不提前请求。T0 首次解码时间与区块创建时间分开解释。收录期间约每 20 秒轮询新签名，每 10 分钟保存进度，同一输出目录可按已保存时钟续跑。

## 离线检查

从本目录运行，使用 Python 3.10 或以上；集群脚本使用 Python 3.12。以下命令不启动实采：

```bash
python3 run_mvp.py --check
python3 -m unittest discover -s tests -v
python3 run_mvp.py --mode fixture --output /tmp/pumpfun-7day-fixture
```

输出应选择新的可写位置。fixture 只读本地样例，其日期不属于实采事件。离线样例应生成 4 个事件、16 条计划和 96 条字段记录。

## 文件入口

- `run_mvp.py`：离线样例、协议检查和实采入口。
- `mvp/acquire_chain.py`：交易查询、创建指令解码和 RPC 回退。
- `mvp/schedule.py`、`mvp/live_cohort.py`：窗口、观察安排和断点续跑。
- `mvp/observe_metadata.py`：声明 URI、网关路线、策略拒绝和请求记录。
- `mvp/build_release.py`：字段、覆盖账本、校验和发布清单。
- `mvp/rpc_helpers.py`：显式 RPC 选择的登记辅助函数。
- `fill_gap.py`：历史区块缺口扫描与合并工具；工具存在不代表已执行或完成全窗口重建。脚本含集群写入、作业取消和重提交流程，运行前确认目标目录。
- `probe_live.py`：少量实时连通性探测，不开启七日队列。
- `figures/`：本轮四张统计图和原集群作图脚本，数据、输出与字体路径需按本机调整。
