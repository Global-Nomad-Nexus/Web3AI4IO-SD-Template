## 本层目录是 P0/P1

- processed/：原阶段 Registry、crosswalk、元数据覆盖、市场及时间连接表。
- raw/、provenance/：原始响应、规则、请求、历史文件清单和哈希。
- reports/：完成报告、覆盖、来源能力、异常和验收。
- code/、configs/、tests/：构建、验证、复现及固定配置。
- figures/、manuscript/：该阶段的图表预览和写作记录。
- archive/P0_P1_logs/：探测与测试的历史控制台日志。

本层的数据、代码和原始证据也是 P2/P3 的固定输入。阶段之间的目录位置具有依赖意义，使用时保留整个 registry_polymarket 及其引用的旧七日数据包。

## 复现与口径

P0/P1 的离线入口是 code/reproduce_offline.py；P2 和 P3 的入口分别见各自 README。建议在完整目录副本中使用固定 Python 3.14.2 进行复现。

历史阶段报告的“未采集”“来源尚未闭合”等描述代表该报告的生成时点。最新一周数量与完成状态以 P3 v6 为准；价格仍限回溯展示，直接币身份映射为 0。旧历史元数据计划不扩写，缺失正文与签名继续在异常表中说明。
