# Data rights and attribution

The repository code license does not grant rights in third-party market questions, rules, token names, metadata values, URLs, images or API response bodies. This branch supplies research records and the author's collection/processing implementation; it makes no blanket claim that all external content is openly licensed.

The frozen source-by-source register is [`source_rights.csv`](source/2026-10-27/registry_polymarket/p4/configs/source_rights.csv). It records provider, endpoint, acquisition scope, attribution, local retention, derived-publication review and raw-redistribution review separately. Many entries remain `not_reviewed`, `requires_rights_review`, or `unknown_not_authorized_for_public_release`. Those entries are historical review findings, preserved verbatim; publication here does not represent that missing permissions have been obtained. Reusers must check the relevant source terms for their intended use.

Sources include public Solana, Base and BSC RPC endpoints, Solana Vibe Station, SQD, ClickHouse CryptoHouse, and Polymarket Gamma / historical price APIs. The legacy six-table collection also records values supplied by individual token metadata publishers. Exact endpoints, retrieval times, source references and evidence hashes are retained in the protocols, data tables and input capsule.

Only public chain addresses and research identifiers should be used for joins. Do not infer a natural person's identity from an address. Metadata unavailability is an observation state; it does not establish token death, misconduct or a lifecycle outcome.

The original P4 local-review data card and release metadata are retained as provenance. The current GitHub distribution is identified as `shilin-v2-20261029`; it is distinct from the historical `p4_personal_candidate_20261029` artifact. There is no DOI, official Croissant validation, or completed joint lifecycle release claimed here.
