# Responsible-AI metadata worksheet

This is an author worksheet, not valid Croissant metadata. Transfer completed answers into a real Croissant document and validate against the [current NeurIPS instructions](https://neurips.cc/Conferences/2026/EvaluationsDatasetsHosting).

| Field | Author input with evidence and scope |
|---|---|
| rai:dataLimitations | AUTHOR INPUT: applicability limits and uses lacking support |
| rai:dataBiases | AUTHOR INPUT: selection/measurement/annotation bias in each source and the joined population |
| rai:personalSensitiveInformation | AUTHOR INPUT: direct, inferred and linkage-enabled sensitive information |
| rai:dataUseCases | AUTHOR INPUT: measured construct, established use cases and unvalidated uses |
| rai:dataSocialImpact | AUTHOR INPUT: affected groups, plausible benefits/harms and actual mitigation evidence |
| rai:hasSyntheticData | AUTHOR INPUT: Boolean for the real release and where synthetic content occurs |
| prov:wasDerivedFrom | AUTHOR INPUT: exact source dataset URIs and immutable revisions |
| prov:wasGeneratedBy | AUTHOR INPUT: collection, extraction, processing, annotation and integration activities |

Complete per component as well as for integration. A source-level privacy assessment may change when records are linked. Record the validator version, date, result and tested file URL in the release receipt.
